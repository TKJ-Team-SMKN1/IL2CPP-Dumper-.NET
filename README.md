# IL2CPP-Dumper-.NET

A simplified .NET-based IL2CPP static analysis and metadata tooling project.

## Project Goals

- Parse Unity IL2CPP metadata
- Inspect supported binary formats
- Produce structured analysis output
- Provide a simple Run-n-Go workflow for Google Colab
- Keep the code modular and testable

## Development Workflow

Acode → GitHub → Google Colab

- Acode: source editing
- GitHub: source of truth
- Colab: build, test, and execution environment

## Safety

This project is intended for static analysis of binaries and metadata that
the user is authorized to analyze.
